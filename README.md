## 🚀 Bắt đầu trong 3 phút

1. Mở [`01-prompts/00-nen-tang.md`](./01-prompts/00-nen-tang.md), copy **Prompt #1 – Hồ sơ doanh nghiệp**.
2. Điền thông tin của bạn vào các chỗ `[...]`, gửi cho AI → lưu lại kết quả.
3. Từ đó, mỗi prompt khác chỉ cần dán thêm “Hồ sơ doanh nghiệp” lên đầu là AI hiểu bạn bán gì, cho ai.
